# Thinking Before Coding Skill

Universal behavioral guidelines for AI coding, based on Karpathy's principles.

## Quick Start

This skill is **automatically loaded** when you ask Copilot to:
- Write code for a feature
- Fix a bug
- Refactor code
- Change architecture

## The Four Principles

1. **Think Before Coding** — State assumptions, surface ambiguities, ask before building
2. **Simplicity First** — Minimum code, no speculation, no over-engineering
3. **Surgical Changes** — Touch only what's needed, don't refactor adjacent code
4. **Goal-Driven Execution** — Define success criteria, verify before finalizing

## When This Matters Most

✅ **USE THIS SKILL FOR:**
- Feature implementations
- Bug fixes
- Architecture changes
- Refactoring work
- API design

⏭️ **NOT REQUIRED FOR:**
- Typo fixes
- One-liner changes
- Simple documentation updates
